# SVM 分类实验：识别垃圾邮件

本实验选用《04_SVM_Detail》真实数据分析案例 ① 的 Spambase，用 57 个数值特征预测邮件是否为垃圾邮件（1 为垃圾邮件，0 为正常邮件）。

## 数据与预处理

数据来自 [UCI Machine Learning Repository 的 Spambase](https://archive.ics.uci.edu/dataset/94/spambase)。原始数据包含 4,601 条记录，2,788 条正常邮件、1,813 条垃圾邮件。57 个特征包括 48 个词频、6 个字符频率和 3 个连续大写字母长度统计量。程序直接读取 [UCI 官方 ZIP](https://archive.ics.uci.edu/static/public/94/spambase.zip) 内的 `spambase.data`，最后一列是标签。

为避免相同特征同时进入训练集和测试集，划分前将同标签的重复特征向量保留一条，并移除标签冲突的 3 组特征向量。测试集占 20%，按类别分层抽样，随机种子为 42。标准化与 SVM 放在同一条 Pipeline 中，每次仅用对应训练折拟合标准化器，测试集只用于最后评估。

## 模型与评估

- 多数类基线始终预测正常邮件，用来观察类别比例对准确率的影响。
- 线性核 SVM 学习线性决策边界，对比 `C ∈ {0.1, 1, 10}`。较大的 `C` 对训练错误施加更重的惩罚。
- RBF 核 SVM 在相同的 `C` 网格上额外比较 `gamma ∈ {0.01, 0.1, scale}`，以允许非线性边界。较大的 `gamma` 缩小单个样本对周围决策区域的影响范围。
- 两个 SVM 都用训练集的五折分层交叉验证按垃圾邮件 F1 选参。最终报告准确率、垃圾邮件精确率、召回率、F1，以及混淆矩阵中的四种计数。误报 FP 是把正常邮件标成垃圾，漏报 FN 是让垃圾邮件通过。

## 实测结果

清洗后留下 4,204 条记录，正常邮件 2,528 条，垃圾邮件 1,676 条。训练集 3,363 条（正常 2,022，垃圾 1,341），测试集 841 条（正常 506，垃圾 335）。

| 模型 | 最佳参数 | 五折 F1 均值 ± 标准差 | 准确率 | 精确率 | 召回率 | F1 | TN / FP / FN / TP |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| 多数类基线 | 始终预测正常 | — | 60.17% | 0.00% | 0.00% | 0.00% | 506 / 0 / 335 / 0 |
| 线性核 SVM | C=0.1 | 0.9058 ± 0.0106 | 92.39% | 90.94% | 89.85% | 90.39% | 476 / 30 / 34 / 301 |
| RBF 核 SVM | C=10，gamma=0.01 | 0.9070 ± 0.0088 | 93.34% | 91.64% | 91.64% | 91.64% | 478 / 28 / 28 / 307 |

多数类基线虽然有 60.17% 的准确率，却漏掉了全部 335 封垃圾邮件。RBF 在本次测试集上比线性核多判对 8 封，误报从 30 降到 28，漏报从 34 降到 28。两者交叉验证平均 F1 只差 0.0012，而且这次实验只有一次固定的留出划分，尚无法判断 RBF 的优势能否稳定复现。

一次本机运行中，线性核搜索加最终拟合用时约 5.93 秒，RBF 约 9.29 秒。两者分别试了 3 组和 9 组参数，因此这组总耗时同时受网格大小影响。数据来自历史邮件，迁移到其他时期或邮箱时，应重新采样评估。

## 复现

本次使用 Windows、Python 3.13.9、scikit-learn 1.9.1、NumPy 2.5.5 和 SciPy 1.18.1。在本目录执行：

```bash
python -m pip install scikit-learn==1.9.1 numpy==2.5.5 scipy==1.18.1
python svm_spambase.py
```

若已下载 UCI ZIP，可执行 `python svm_spambase.py --archive /path/to/spambase.zip`。脚本会打印数据规模、最佳参数、评估指标及混淆矩阵计数。

源码位于 [svm_spambase.py](svm_spambase.py)。
