# 用 SVM 分垃圾邮件

我用的是 [UCI 的 Spambase](https://archive.ics.uci.edu/dataset/94/spambase)，想看看用线性核和 RBF 核做垃圾邮件分类，结果能差多少。这个数据集没有邮件正文，每封邮件用 57 个数字表示，包括词频、字符频率和一串连续大写字母有多长。最后一列是标签，`1` 是垃圾邮件，`0` 是正常邮件。

## 数据怎么分

原始数据有 4,601 条。我先检查了一遍重复记录。有些记录的 57 个数值完全一样，标签也一样，这种只留一条。另外有 3 组特征完全一样、标签却不同的记录，我把这 3 组都去掉了。这样，同一组特征就不会同时出现在训练集和测试集里。

处理后剩下 4,204 条，其中 2,528 条是正常邮件，1,676 条是垃圾邮件。我按类别比例分出 841 条做测试，剩下的 3,363 条用来训练，随机种子设为 42。

## 我试了哪些模型

我先跑了一个最简单的基线，把所有邮件都判成正常邮件，看看光靠猜多数类能拿多少准确率。然后跑了两种 SVM。两种核都试了 `C=0.1、1、10`，RBF 核还试了 `gamma=0.01、0.1、scale`。参数是在训练集上做五折分层交叉验证选的，我用垃圾邮件的 F1 作为选参标准。每一折的标准化也只用那一折的训练数据来算，最后才拿测试集比较。

## 跑出来的结果

| 模型 | 选出的参数 | 五折 F1 均值 ± 标准差 | 测试准确率 | 精确率 | 召回率 | F1 | 误报 | 漏报 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 全判正常 | — | — | 60.17% | 0.00% | 0.00% | 0.00% | 0 | 335 |
| 线性核 SVM | `C=0.1` | 0.9058 ± 0.0106 | 92.39% | 90.94% | 89.85% | 90.39% | 30 | 34 |
| RBF 核 SVM | `C=10, gamma=0.01` | 0.9070 ± 0.0088 | 93.34% | 91.64% | 91.64% | 91.64% | 28 | 28 |

测试集里有 335 封垃圾邮件。全部判成正常，准确率也有六成，但一封垃圾邮件都抓不到。看两个 SVM 的结果，RBF 这次多抓到了 6 封垃圾邮件，还少把 2 封正常邮件误判为垃圾邮件。不过五折平均 F1 只差 0.0012，换一批测试数据，差距可能会变。

我这边跑了一次，线性核调参和训练大约用了 6 秒，RBF 大约用了 9 秒。线性核试了 3 组参数，RBF 试了 9 组，所以这个时间差也包括多试参数的开销。

## 怎么运行

在 Python 3.13.9 下，我用的是下面这组依赖。脚本会从 UCI 下载数据并打印结果。

```bash
python -m pip install scikit-learn==1.9.1 numpy==2.5.5 scipy==1.18.1
python svm_spambase.py
```

如果已经下载了 [Spambase 数据压缩包](https://archive.ics.uci.edu/static/public/94/spambase.zip)，也可以用 `python svm_spambase.py --archive spambase.zip`。
