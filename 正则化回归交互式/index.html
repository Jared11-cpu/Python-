推导与分析

正交设计下为什么是等比例收缩？

对 ‖y − Xβ‖² + λ‖β‖² 求导并令其为零，得到 (XᵀX + λI)β̂ = Xᵀy。当 X 的列正交且已归一化时，XᵀX = I，此时 OLS 系数为 Xᵀy，因此 β̂Ridge = β̂OLS / (1 + λ)。如果列只正交，且第 j 列的平方范数为 dⱼ，则该列的收缩因子是 dⱼ / (dⱼ + λ)。这里默认截距单独处理。

为什么 XᵀX + λI 严格正定？

对任意非零向量 v，有 vᵀ(XᵀX + λI)v = ‖Xv‖² + λ‖v‖² ≥ λ‖v‖² > 0，因为 λ > 0。矩阵对称，所以它严格正定，即使 X 秩亏也有唯一的 Ridge 系数解。

变量的单位为什么会影响惩罚？

把一个变量从米改为厘米，数值放大 100 倍。要维持相同的预测，它的系数就缩小为原来的 1/100，Lasso 对该系数的惩罚也缩小为 1/100，Ridge 则缩小为 1/10000。先用 Z-score 把系数放在“每增加一个标准差”的尺度上，可减少单位带来的偏差。截距由模型单独拟合，且不受惩罚。
