# 第3题：三个小问

## 1. 模型拟合报告与基准组

400 个样本，拟合方程为：

```math
\begin{aligned}
\widehat{Sales}={}&10.3916-0.0570\,Price+0.0137\,Income\\
&+0.1056\,Advertising+4.8359\,I_{Good}+1.8959\,I_{Medium}.
\end{aligned}
```

其中，门店属于对应货架类别时，指示变量取 1，否则取 0。

```math
R^2=0.6268,\qquad R^2_{\mathrm{adj}}=0.6221,\qquad
F(5,394)=132.4,\quad p\approx4.89\times10^{-82}.
```

**基准组是 Bad**，其两个指示变量均为 0。模型整体显著，解释了约 62.68% 的样本销量变异。完整系数、标准误和检验结果见[模型拟合报告](第3题_运行结果.txt)。

## 2. ShelveLoc[Good] 的商业含义

```math
\hat\beta_{Good}=4.8359.
```

价格、收入和广告预算相同时，Good 组门店的预测销量比 Bad 组平均高 **4.8359 千件，约 4836 件**。较好的陈列位置与更高销量相关，但不能仅凭该回归断定因果关系。

## 3. VIF 与多重共线性

```math
VIF_j=\frac{1}{1-R_j^2}.
```

其中，$`R_j^2`$ 来自用其余解释变量对第 $`j`$ 个解释变量作含截距的回归。

| 变量 | VIF |
| --- | ---: |
| Price | 1.0077 |
| Income | 1.0124 |
| Advertising | 1.0094 |
| ShelveLoc[Good] | 1.4973 |
| ShelveLoc[Medium] | 1.4938 |

ShelveLoc 按两个虚拟变量分别计算。各项 VIF 均接近 1，且低于常用参考值 5，**无明显多重共线性风险**。
