# 第3题解答

## 1. 模型结果

用 400 个样本拟合，结果是：

```math
\widehat{Sales} = 10.3916 - 0.0570\,Price + 0.0137\,Income
+ 0.1056\,Advertising + 4.8359\,I_{Good} + 1.8959\,I_{Medium}
```

R²≈0.627，调整后的 R²≈0.622，F 检验的 p 值非常小，模型整体显著。

基准组是 Bad（两个指示变量都为 0）。

完整输出见运行结果文件。

## 2. ShelveLoc[Good] 的含义

系数是 4.8359，意思是在价格、收入、广告都相同的情况下，Good 组的预测销量比 Bad 组高大约 4.84 千件（约 4836 件）。

这里只能说是相关关系，不能直接断定是因果关系。
