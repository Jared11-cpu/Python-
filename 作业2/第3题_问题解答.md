# 第3题解答

## 1. 模型结果

我用 Carseats 的 400 条记录拟合销量。货架位置有三个等级，取 Bad 作基准，给 Good 和 Medium 各设一个指示变量。拟合式如下：

```math
\widehat{Sales} = 10.3916 - 0.0570\,Price + 0.0137\,Income
+ 0.1056\,Advertising + 4.8359\,I_{Good} + 1.8959\,I_{Medium}
```

两个指示变量都取 0 时，就得到 Bad 组的预测值。$R^2$ 约为 0.627，调整后的 $R^2$ 约为 0.622。整体 F 检验的 p 值很小，可以拒绝所有斜率同时为 0 的假设。[完整运行结果](第3题_运行结果.txt)

## 2. ShelveLoc[Good] 的含义

可以拿两个价格、收入和广告投入都相同的门店来想。一个是 Good，另一个是 Bad，代进同一条式子，预测销量就差 4.8359 千件，也就是大约 4836 件。这个差值描述的是样本中的关联。

## 3. VIF

| 变量 | VIF |
| --- | ---: |
| Price | 1.0077 |
| Income | 1.0124 |
| Advertising | 1.0094 |
| ShelveLoc[Good] | 1.4973 |
| ShelveLoc[Medium] | 1.4938 |

表里最高的是 Good 的 1.4973，和常用的参考值 5 还差得比较远。从这组 VIF 看，自变量之间没有明显的多重共线性。
