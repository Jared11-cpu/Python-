# 第3题结果说明

## （1）回归结果

这次一共用了 400 条数据。回归方程为：

```math
\widehat{Sales}
=10.3916-0.0570Price+0.0137Income+0.1056Advertising
+4.8359Good+1.8959Medium.
```

这里把 ShelveLoc 中的 Bad 作为参照组，所以 Bad 不需要单独设置虚拟变量。模型的 $R^2=0.6268$，调整后的 $R^2=0.6221$，大约能解释 62.68% 的销量差异。

从输出的 P 值来看，这几个变量在本模型中都是显著的。完整结果放在第3题_运行结果.txt中。

## （2）Good 系数怎么理解

Good 的系数是 4.8359。按照这个模型，在 Price、Income 和 Advertising 保持相同的情况下，货架位置为 Good 的商店比 Bad 的商店预测销量高约 4.836 千件。

## （3）VIF

程序算出的结果是：

| 变量 | VIF |
| --- | ---: |
| Price | 1.0077 |
| Income | 1.0124 |
| Advertising | 1.0094 |
| ShelveLoc[Good] | 1.4973 |
| ShelveLoc[Medium] | 1.4938 |

这些数都不大，最高也只有 1.4973，因此这几个自变量之间没有明显的多重共线性问题。
