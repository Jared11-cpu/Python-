# 第2题：加入无关变量后 R² 的变化

原来的回归模型加入一个无关变量后，新模型其实包含了原模型，因为只要把新变量的系数取成 0，就能得到原来的模型。因此重新拟合后，残差平方和只可能减小或不变：

```math
RSS_{new}\leq RSS_{old}.
```

样本没有变化，所以 $TSS$ 不变。由

```math
R^2=1-\frac{RSS}{TSS}
```

可以得到

```math
R^2_{new}\geq R^2_{old}.
```

所以即使加入的是无关变量，普通 $R^2$ 也不会下降。不过这不代表模型真的变好了，因为新变量也可能只是碰巧解释了一点样本中的波动。

调整后的 $R^2$ 还考虑了变量个数。设原模型有 $p$ 个自变量，则

```math
R^2_{adj,old}
=1-\frac{RSS_{old}/(n-p-1)}{TSS/(n-1)},
```

加入一个变量后变为

```math
R^2_{adj,new}
=1-\frac{RSS_{new}/(n-p-2)}{TSS/(n-1)}.
```

虽然 $RSS$ 会减小，但残差自由度也少了 1。如果这个无关变量只能让 $RSS$ 降低一点，调整后的 $R^2$ 就会下降；如果它碰巧让 $RSS$ 降得比较多，也可能上升。

结论：普通 $R^2$ 不会下降，调整后的 $R^2$ 通常会下降，但不是绝对的。
