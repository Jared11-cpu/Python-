# 第2题：加入无关变量后的决定系数

设样本量为 $`n`$，原模型含 $`p`$ 个自变量及截距。记加入变量前后为 old、new，假设样本相同、新变量增加一个自由参数，且 $`n\gt p+2`$、$`TSS\gt 0`$。

## 1. 普通决定系数

```math
R^2=1-\frac{RSS}{TSS},\qquad
TSS=\sum_{i=1}^{n}(y_i-\bar y)^2.
```

新增变量的系数取零即可还原原模型，因此最小二乘拟合满足：

```math
RSS_{\mathrm{new}}\le RSS_{\mathrm{old}},\quad TSS\text{ 不变}
\quad\Longrightarrow\quad
\boxed{R^2_{\mathrm{new}}\ge R^2_{\mathrm{old}}}.
```

随机变量也可能偶然拟合样本中的噪声，使 RSS 下降。因此，普通决定系数的增加不一定代表模型预测能力提高。

## 2. 调整后的决定系数

```math
\begin{aligned}
R^2_{\mathrm{adj,old}}
&=1-\frac{RSS_{\mathrm{old}}/(n-p-1)}{TSS/(n-1)},\\
R^2_{\mathrm{adj,new}}
&=1-\frac{RSS_{\mathrm{new}}/(n-p-2)}{TSS/(n-1)}.
\end{aligned}
```

原模型估计 $`p+1`$ 个参数，新增变量后估计 $`p+2`$ 个参数，因此残差自由度由 $`n-p-1`$ 减为 $`n-p-2`$。调整后的决定系数比较的是 RSS 除以残差自由度，而非只比较 RSS。

记 $`\Delta RSS=RSS_{\mathrm{old}}-RSS_{\mathrm{new}}`$，则：

```math
\begin{aligned}
R^2_{\mathrm{adj,new}}\lt R^2_{\mathrm{adj,old}}
&\iff \frac{RSS_{\mathrm{new}}}{n-p-2}
\gt \frac{RSS_{\mathrm{old}}}{n-p-1}\\
&\iff \boxed{\Delta RSS\lt
\frac{RSS_{\mathrm{old}}}{n-p-1}}.
\end{aligned}
```

无关变量若只使 RSS 小幅下降，不足以补偿自由度的损失，调整后的决定系数就会下降。

**并非必然下降**：若偶然使 RSS 的降幅超过上述阈值，调整后的决定系数也会上升；等于阈值时不变。

## 3. 简例

取 $`n=100`$、$`p=3`$、$`TSS=1000`$，加入变量后 RSS 从 200 降至 199：

| 指标 | 加入前 | 加入后 |
| --- | ---: | ---: |
| 残差自由度 | 96 | 95 |
| R² | 0.800 | 0.801 |
| 调整后的 R² | 0.79375 | 0.79262 |

RSS 仅下降 1，小于阈值 $`200/96\approx2.0833`$，所以普通决定系数上升，调整后的决定系数下降。
