# 第2题：加入无关变量后的决定系数

样本量为 $n$，原模型有 $p$ 个自变量和一个截距。

### 1. 普通 R²

```math
R^2 = 1 - \frac{RSS}{TSS}
```

新模型可以取新变量系数为 0，所以一定有 $RSS_{new}\leq RSS_{old}$。TSS 不变，因此 $R^2$ 不会下降。

但随便加一个无关变量也可能碰巧拟合一点噪声，所以 R² 上升不一定说明模型真的更好。

### 2. 调整后的 R²

```math
R^2_{adj} = 1 - \frac{RSS/(n-k-1)}{TSS/(n-1)}
```

其中 $k$ 是自变量个数。

加入一个变量后，自由度从 $n-p-1$ 变成 $n-p-2$。如果 RSS 下降得不够多，调整后的 R² 反而会变小。

具体来说，当

```math
\Delta RSS < \frac{RSS_{old}}{n-p-1}
```

时，调整后的 R² 会下降。

### 3. 简单算个例子

假设 $n=100$，$p=3$，$TSS=1000$，RSS 从 200 降到 199：

- 原来：自由度 96，R²=0.8，调整后 R²≈0.7938
- 后来：自由度 95，R²=0.801，调整后 R²≈0.7926

RSS 只少了 1，小于 $200/96\approx2.08$，所以调整后的 R² 掉了。
