# 第2题：加入无关变量后的决定系数

样本量为 $n$，原模型有 $p$ 个自变量和一个截距。

### 1. 普通 R²

```math
R^2 = 1 - \frac{RSS}{TSS}
```

把新变量的系数设成 0，就能得到原来的拟合结果。重新做最小二乘时，RSS 最多和原来一样。用的还是同一批 $y$，TSS 固定，所以 $R^2$ 只能持平或上升。哪怕加进来的是个无关变量，它也可能刚好拟合掉一点样本里的噪声。

### 2. 调整后的 R²

```math
R^2_{adj} = 1 - \frac{RSS/(n-k-1)}{TSS/(n-1)}
```

这里 $k$ 是自变量个数。多放一个变量，残差自由度就从 $n-p-1$ 少到 $n-p-2$。把新旧两个 RSS 分别除以各自的自由度，就能看出 RSS 降得够不够。记 $\Delta RSS=RSS_{old}-RSS_{new}$，调整后的 $R^2$ 会在下面这个条件下下降：

```math
\Delta RSS < \frac{RSS_{old}}{n-p-1}
```

### 3. 代入数字看看

假设有 100 条记录，原来放了 3 个自变量，TSS 是 1000。加一个变量后，RSS 从 200 降到 199：

- 原来：自由度 96，R²=0.8，调整后 R²≈0.7938
- 后来：自由度 95，R²=0.801，调整后 R²≈0.7926

RSS 只少了 1，小于 $200/96\approx2.08$，所以调整后的 R² 掉了。
