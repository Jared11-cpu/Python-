# 第1题：残差的两个性质

设模型含截距项，采用普通最小二乘法：

```math
\hat y_i=\hat\beta_0+\hat\beta_1x_i,\qquad
e_i=y_i-\hat y_i.
```

最小化残差平方和：

```math
RSS(\beta_0,\beta_1)
=\sum_{i=1}^{n}(y_i-\beta_0-\beta_1x_i)^2.
```

在最小二乘估计处，两个偏导数均为零：

```math
\begin{aligned}
\left.\frac{\partial RSS}{\partial\beta_0}\right|_{\hat\beta_0,\hat\beta_1}
&=-2\sum_{i=1}^{n}e_i=0,\\
\left.\frac{\partial RSS}{\partial\beta_1}\right|_{\hat\beta_0,\hat\beta_1}
&=-2\sum_{i=1}^{n}x_ie_i=0.
\end{aligned}
```

因此：

```math
\boxed{\sum_{i=1}^{n}e_i=0},\qquad
\boxed{\sum_{i=1}^{n}x_ie_i=0}.
```

残差均值为零，且与自变量正交。若不含截距项，第一个结论不一定成立。
