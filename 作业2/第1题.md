# 第1题：一元线性回归中残差的两个性质

设一元线性回归的拟合方程为

```math
\hat y_i=\hat\beta_0+\hat\beta_1x_i,
```

残差为 $`e_i=y_i-\hat y_i`$。这里讨论的是**含截距项的普通最小二乘回归**。

最小二乘法选择 $`\hat\beta_0`$ 和 $`\hat\beta_1`$，使残差平方和

```math
RSS(\beta_0,\beta_1)=\sum_{i=1}^{n}(y_i-\beta_0-\beta_1x_i)^2
```

达到最小。分别对两个参数求偏导，在最小值处有

```math
\left.\frac{\partial RSS}{\partial\beta_0}\right|_{\hat\beta_0,\hat\beta_1}
=-2\sum_{i=1}^{n}(y_i-\hat\beta_0-\hat\beta_1x_i)=0.
```

括号内就是 $`e_i`$，所以

```math
\boxed{\sum_{i=1}^{n}e_i=0}.
```

同样，对斜率求偏导可得

```math
\left.\frac{\partial RSS}{\partial\beta_1}\right|_{\hat\beta_0,\hat\beta_1}
=-2\sum_{i=1}^{n}x_i(y_i-\hat\beta_0-\hat\beta_1x_i)=0,
```

因此

```math
\boxed{\sum_{i=1}^{n}x_ie_i=0}.
```

这两个等式分别说明：残差的平均值为零，残差与自变量在样本中正交。因为 $`\bar e=0`$，还有

```math
\sum_{i=1}^{n}(x_i-\bar x)(e_i-\bar e)
=\sum_{i=1}^{n}x_ie_i-\bar x\sum_{i=1}^{n}e_i=0.
```

因此，残差与自变量的样本协方差也为零。这是最小二乘估计带来的代数性质，并不需要假设误差服从正态分布。若模型不含截距项，残差之和为零就不一定成立。
