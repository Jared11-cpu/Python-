# 第1题：残差的两个性质

这里用带截距的一元线性回归。残差就是实际值减去拟合值：

```math
\hat{y}_i = \hat\beta_0 + \hat\beta_1 x_i,\quad e_i = y_i - \hat{y}_i
```

OLS 要找的是让下面这个平方和最小的截距和斜率：

```math
RSS = \sum (y_i - \beta_0 - \beta_1 x_i)^2
```

先对截距求偏导。在最小值处代入估计值，括号里的差就是残差 $e_i$：

```math
\frac{\partial RSS}{\partial\beta_0} = -2\sum e_i = 0
\implies \sum e_i = 0
```

再对斜率求偏导，这次每个残差前会多一个 $x_i$：

```math
\frac{\partial RSS}{\partial\beta_1} = -2\sum x_i e_i = 0
\implies \sum x_i e_i = 0
```

第一式说明正负残差加起来刚好是 0。第二式里的和是残差向量和自变量向量的内积，等于 0 就是正交。整个推导只用到了最小二乘的一阶条件。去掉截距后，就少了第一条求导等式。
