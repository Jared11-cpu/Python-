# 第1题：残差的两个性质

设模型含截距项，采用普通最小二乘法：

```math
\hat y_i=\hat\beta_0+\hat\beta_1x_i,\qquad
e_i=y_i-\hat y_i.
```

最小二乘法选择截距和斜率，使残差平方和最小：

```math
RSS(\beta_0,\beta_1)
=\sum_{i=1}^{n}(y_i-\beta_0-\beta_1x_i)^2.
```

分别对截距和斜率求偏导：

```math
\begin{aligned}
\frac{\partial RSS}{\partial\beta_0}
&=-2\sum_{i=1}^{n}(y_i-\beta_0-\beta_1x_i),\\
\frac{\partial RSS}{\partial\beta_1}
&=-2\sum_{i=1}^{n}x_i(y_i-\beta_0-\beta_1x_i).
\end{aligned}
```

在最小值处偏导数为零。代入估计值后，括号内即为残差 $`e_i`$：

```math
\begin{aligned}
\left.\frac{\partial RSS}{\partial\beta_0}\right|_{\hat\beta_0,\hat\beta_1}
&=-2\sum_{i=1}^{n}e_i=0,\\
\left.\frac{\partial RSS}{\partial\beta_1}\right|_{\hat\beta_0,\hat\beta_1}
&=-2\sum_{i=1}^{n}x_ie_i=0.
\end{aligned}
```

因此：

```math
\boxed{\sum_{i=1}^{n}e_i=0},\qquad
\boxed{\sum_{i=1}^{n}x_ie_i=0}.
```

第一个等式表示残差均值为零，第二个等式表示残差与自变量正交。这是最小二乘法的代数性质，不依赖误差的正态性假设。

注意：第一个结论来自对截距求导；若模型不含截距项，残差之和不一定为零。
