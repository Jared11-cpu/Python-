# 第1题：残差的两个性质

模型含截距，用 OLS：

```math
\hat{y}_i = \hat\beta_0 + \hat\beta_1 x_i,\quad e_i = y_i - \hat{y}_i
```

最小化残差平方和：

```math
RSS = \sum (y_i - \beta_0 - \beta_1 x_i)^2
```

对 $\beta_0$ 和 $\beta_1$ 分别求偏导，并令它们等于 0：

```math
\frac{\partial RSS}{\partial\beta_0} = -2\sum e_i = 0
\implies \sum e_i = 0
```

```math
\frac{\partial RSS}{\partial\beta_1} = -2\sum x_i e_i = 0
\implies \sum x_i e_i = 0
```

所以残差之和为 0，残差与自变量也正交。

注：这两个性质是从最小化条件直接推出来的，和误差是否正态没关系。另外如果模型没有截距，第一个性质就不一定成立了。
