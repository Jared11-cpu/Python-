# 第1题：残差的性质

回归模型中有截距项，记

```math
\hat y_i=\hat\beta_0+\hat\beta_1x_i,\qquad e_i=y_i-\hat y_i.
```

最小二乘法就是让下面的残差平方和最小：

```math
RSS=\sum_{i=1}^{n}(y_i-\beta_0-\beta_1x_i)^2.
```

分别对 $\beta_0$ 和 $\beta_1$ 求导，并令结果为 0：

```math
-2\sum_{i=1}^{n}(y_i-\hat\beta_0-\hat\beta_1x_i)=0,
```

```math
-2\sum_{i=1}^{n}x_i(y_i-\hat\beta_0-\hat\beta_1x_i)=0.
```

括号里的部分就是残差 $e_i$，所以有

```math
\sum_{i=1}^{n}e_i=0,\qquad \sum_{i=1}^{n}x_ie_i=0.
```

也就是说，残差的平均值为 0，并且残差与自变量 $x$ 正交。这两个结论都是由最小二乘的一阶条件得到的。
