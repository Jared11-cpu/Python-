① WCSS 的成对距离等价形式

把一个簇的样本数记作 n，质心为 μ = (Σᵢxᵢ)/n。展开到质心的平方距离，再利用 Σᵢxᵢ = nμ：

Σᵢ‖xᵢ − μ‖² = Σᵢ‖xᵢ‖² − 2μᵀΣᵢxᵢ + n‖μ‖² = Σᵢ‖xᵢ‖² − n‖μ‖²。

对成对距离求和时，每个样本的平方范数分别在两个求和指标上出现 n 次，内积项则可以合并：

ΣᵢΣⱼ‖xᵢ − xⱼ‖² = 2nΣᵢ‖xᵢ‖² − 2‖Σᵢxᵢ‖² = 2n(Σᵢ‖xᵢ‖² − n‖μ‖²)。

因此双重求和除以 2n 就得到 WCSS。双重求和把每一对不同样本按两个顺序都算了一次。

② Ward 聚类合并的方差增加量

令 N = nA + nB，合并后的质心为 μ = (nAμA + nBμB)/N。对 A 中的点，把 x − μ 写成 (x − μA) + (μA − μ)。平方求和后，交叉项因 Σx∈A(x − μA) = 0 而消失。B 同理。

ΔESS = ESS(A∪B) − ESS(A) − ESS(B) = nA‖μA − μ‖² + nB‖μB − μ‖²。

由合并质心公式，μA − μ = (nB/N)(μA − μB)，μB − μ = −(nA/N)(μA − μB)。代回后，系数是 (nAnB² + nBnA²)/N² = nAnB/N。

ΔESS = [nAnB/(nA + nB)] ‖μA − μB‖²。

③ 维度灾难与前置处理

如果许多坐标大致独立、尺度相近，两点的平方距离就是许多项相加。随着维度上升，和的均值通常按维度增长，标准差只按维度平方根增长，远近距离的相对差异随之缩小。K-Means 的平方距离容易被大量无关坐标左右。对 DBSCAN 来说，固定样本量下局部邻域变稀疏，ε 稍小就可能留下许多噪声点，调大又容易把簇连在一起。

先标准化可以减轻量纲影响，再结合特征筛选、PCA 或 TruncatedSVD 缩减无关维度。方向更重要时可以试余弦距离，稀疏二值特征可考虑 Jaccard。降维后仍要检查邻域是否保留下来，因为最大方差方向可能与簇结构无关。下面的加噪实验可以直接观察这一点。

④ Iris 聚类实战

150 条鸢尾花记录，四个测量特征先做 Z-score。K-Means 遍历 K = 2–8，每个 K 用 20 次初始化；DBSCAN 固定 min_samples = 5。品种标签只用于拟合完成后的 ARI 对照。ARI 越接近 1，聚类与品种划分越一致。
